# Lab 2 – MLP aproksimavimas

Pagrindinė užduotis: 1 įėjimas → 4 `tanh` paslėpti neuronai → 1 tiesinis išėjimas. Backpropagation parašytas neuroną po neurono, dėstytojo stiliumi.

Papildoma užduotis: 2 įėjimai → 4 paslėpti neuronai → 1 išėjimas, aproksimuojamas netiesinis paviršius.
